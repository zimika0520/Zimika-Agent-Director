# 改编策略参考

这些是用于提出方案的启发式规则，不是行业统一标准。先依据原著判断，再由用户确认；受众方向必须与具体题材组合，不能只靠“男频/女频”决定写法。

## 通用戏剧化

- 总原则是“可以增加表达，不得擅自增加故事事实”。全剧地图、批次大纲和每集剧本都要在确认前运行独立内容边界检查，不能把保真检查拖到最终交付。
- 保护核心因果、人物动机和关键冲突，不机械保护每句原文。
- 把抽象心理转为选择、动作、迟疑、隐瞒、对抗、道具或可听内容。
- 一场戏至少改变信息、关系、目标、风险或人物状态之一。
- 解释必须遇到阻力；能通过行动或证据表达时，不用长对白说明。
- 分集按戏剧单元切分，不按章节字数平均切分。
- 钩子来自尚未回答的问题、即将发生的行动、关系改变或风险升级，不只靠“画面骤黑”。

自动允许但必须追溯的范围仅限表达层：心理描写转可见动作、场景衔接、时间压缩、动作补全、不承担新剧情功能的群众/环境反应，以及原著已有事件的戏剧化展开。每项都绑定原著单元和改编决策，并明确不改变故事事实。对白、VO、OS 不做影视化改写，直接引用原著并绑定原著单元和定位。

新命名角色、合并角色、新支线、新关系、新能力、新重大事件、关键事件调序、改变人物选择/事件原因/结果，以及为增强钩子新增重要危机，必须先得到用户具体授权。未经授权新增或改变主要人物、身份、能力、核心关系，改变动机、关键事件、因果、世界规则或结局性质，提前泄露人物尚不知晓的信息，以及无原著依据又无授权的内容，均按阻断处理。

自动核对只能给出证据判断，不能声称百分之百正确：有明确原著依据为 `passed`；有可回查用户授权为 `approved_addition`；证据不足为 `suspected_overreach` 并交人工判断；明确冲突或未经批准主要新增为 `blocked`。

## 事件到戏剧单元

先依据 `SourceEventIndex` 判断事件是否形成“起因 → 人物行动 → 阻力/反馈 → 可验证结果 → 状态变化”。只有摘要但没有状态变化的内容，先回读原文，不直接摊进分集。

- `preserve`：原著行动、结果与人物动机本身已能形成有效场景。
- `compress`：多个段落承担同一信息或同一冲突功能；压缩后仍保留关键选择和后果。
- `merge`：多个事件可以在同一场景完成，但不得制造人物不可能同时在场或知情的矛盾。
- `reorder`：调序能改善信息释放；必须复核因果、时间、知情范围与伏笔先后。
- `omit`：事件对主线、人物弧、关系或后续因果无必要贡献；记录删除后的影响与替代。
- `bridge_addition`：原著跳跃导致剧本行动因果不成立时，只增加有原著事实支撑、且不承担新剧情功能的最小桥接表达；标记改编新增，不改变原著事实。若没有原著依据或产生新的重要危机、选择、原因、结果，必须先获用户授权。

每个选择写入 `AdaptationDecisionLedger`。不能用“节奏更快”“更商业”作为唯一理由；必须说明具体保留了什么、改变了什么、会影响哪些集。

## 受众方向

### 偏男频

常见优先项可能包括目标推进、能力兑现、资源变化、规则博弈、身份升级和对抗结果。检查主角是否通过具体行动改变局面，避免只有旁人吹捧。

### 偏女频

常见优先项可能包括关系张力、情绪递进、主体选择、身份处境、信任变化和情感兑现。检查女主是否有行动权，避免只靠误会拖延或被动承受。

### 泛受众

优先保证清晰目标、普适情绪、强人物关系和易理解的冲突；减少依赖圈层知识才能成立的爽点或虐点。

## 题材叠加示例

- 宅斗/宫斗：身份秩序、资源与证据、公开/私下两个战场。
- 复仇：受害事实、阶段目标、代价、反制和最终清算。
- 甜宠：吸引、试探、共同事件、关系确认与阶段性兑现。
- 权谋：各方目标、信息差、筹码变化和行动后果。
- 悬疑：问题链、线索公平性、误导边界、阶段答案和新问题。
- 穿越/系统：规则尽快转成任务和行动，避免长时间念设定。

这些题材提示只用于诊断，不是固定节拍模板。根据原著另可检查：

- 喜剧：笑点是否来自人物目标、误判和后果，而不是脱离人物的段子；笑点之后剧情状态是否变化。
- 成长：能力、认知和关系的变化是否由事件代价推动，不能只用旁白宣布成长。
- 家庭：冲突各方是否有可理解的利益、情感债和边界；和解必须由行动兑现。
- 动作：每次对抗是否改变目标、资源、伤势或权力，避免重复打斗。
- 心理：主观感受是否被转成行为选择、错误判断或可听信息，同时保留现实层证据。
- 科幻/奇幻：规则是否稳定，能力是否有边界和代价，解决方案是否遵守已建立规则。
- 历史：身份秩序、制度和称谓如无法从来源核验，标记待考证，不用流行短剧称谓替代事实。

## 内容容量

目标时长不等于固定字数。估算时至少考虑对白、动作、停顿、转场和字幕可读性。发现明显超载时，优先压缩重复解释、合并同功能人物/场景或拆分剧情单元；不得为了时长破坏核心因果。
