# 人工完整剧本格式模板（统一剧本模板）

## 用途与边界

本文件从一份 60 集人工完整漫剧文学剧本中提取**结构模板与写作习惯**，用于对齐 AI Director 的剧本生成和 DOCX 交付格式。

本文件不保留原剧本中的角色、剧情、台词、道具、地点或专有名称，全部替换为占位符。使用本模板时，只能借用格式和节奏，不能照搬任何具体故事内容。

## 一、外部交付模板

```text
第N集：集标题

N-M 场景：地点A 日/夜 / 内/外
人物：角色A、角色B
非现场人物：角色C（画外音）、角色D（电话声音；无则省略整行）
道具：道具A、道具B（无则写“无”）

△ 可见动作、走位、表情、道具变化或环境反应。
角色A：对白。
角色A VO：内心独白。
角色B OS：画外对白。
角色C 电话声音：电话对白。

△ 下一个可见动作或反应。
角色B（语气或动作说明）：对白。

【画面骤黑】
```

## 二、从人工稿归纳的结构规则

1. 集标题统一使用：

   ```text
   第N集：集标题
   ```

2. 场标题统一使用：

   ```text
   N-M 场景：地点 时间 / 内外
   ```

   地点、日夜、内外景必须一次写清。

3. 场标题之后依次写：

   - `人物：`
   - `非现场人物：`（按需）
   - `道具：`

4. 可见动作统一用 `△` 开头，一行为一个可执行的画面节拍。

5. 对白直接写：

   ```text
   角色名：对白
   ```

   语气、动作、态度等说明放在角色名后的括号内。

6. 特殊声音类型必须显式标注：

   - `角色名 VO：` 内心独白
   - `角色名 OS：` 画外音
   - `角色名 电话声音：` 电话对白
   - `（字幕：角色身份或关键信息）` 用于首次出场或需要观众快速识别的身份

7. 特殊画面节点：

   - `【闪回画面】`：插入回忆或脑内画面
   - `【画面骤黑】`：本集结束或硬切
   - `【全剧终】`：全剧结束

8. 每场建议形成完整的行动单元：

   - 人物进入当前状态
   - 明确当场任务
   - 出现可见阻力
   - 连续动作或对白推进
   - 出现反应与转折
   - 以信息、关系、位置、物品或危险程度变化收场

## 三、人工稿中观察到的节奏特征

这些是观察到的写法习惯，不是必须写死的行业标准：

- 大多数集为 3 场，个别集为 2 场或 4 场。
- 每场通常包含 3 到 8 个动作节拍。
- 动作节拍之间穿插对白、VO 或 OS，避免长段无动作独白。
- 每集结尾通常落在决策、反转或下一集钩子上，再用 `【画面骤黑】` 断开。
- 人物、场景、道具、台词、VO/OS 都可以直接从文本中提取，不需要导演重新补戏。

## 四、与 AI Director 当前模板的对齐点

AI Director 的对外交付模板已经覆盖：

- `人物：`
- `非现场人物：`
- `道具：`
- `△` 动作
- `角色A VO：`
- `角色B OS：`
- `角色D 电话声音：`

需要进一步对齐的是**集标题和场标题的明文格式**：

```text
第N集：集标题
N-M 场景：地点 日/夜 / 内/外
```

这份格式与 `render_episode_script.py` 期望的正则一致。后续生成文学剧本时应优先输出这种格式，避免为了 DOCX 交付再放宽解析器。

## 五、禁止事项

- 不复制原剧本的角色名、地点名、道具、剧情、对白、VO/OS 文案。
- 不把原剧本当作任何新项目的原著事实来源。
- 不把参考剧本的集数、场数、节奏当作硬性行业标准。
- 不因为参考剧本格式相似就放松内容边界、来源绑定和交付校验。
